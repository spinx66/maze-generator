# Maze Generator

A lightweight browser-based maze generator for creating, solving, and exporting random mazes.

Generate mazes with custom dimensions, visualize solutions instantly, and export them in multiple formats including **PNG, SVG, JSON, and TXT**.

Everything runs directly in your browser, so there is no server, account, or installation required.

### Features

* Random maze generation
* Built-in maze solver
* Custom width and height
* PNG export
* SVG export
* JSON export
* TXT export
* Fully client-side
* Dark, lightweight interface
* No accounts or dependencies required

Built by **Spinx** and released as open source.
